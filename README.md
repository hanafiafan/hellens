# Hellens Developer

Portfolio and digital studio website built as a single modern React application.

## Stack

- Vite
- React 18
- TypeScript
- React Router
- Motion
- Lenis
- Component-based CSS design system

## Commands

```bash
npm run dev
npm run typecheck
npm run build
npm run preview
```

## Structure

- `src/components` — reusable interface and motion components
- `src/context` — shared language state
- `src/data` — project and content data
- `src/hooks` — reusable SEO hooks
- `src/pages` — route-level pages
- `src/styles` — global design system
- `public` — production brand, gallery, project, font, and metadata assets

Routes: `/`, `/projects/:slug`, and `?lang=en` for English content.
